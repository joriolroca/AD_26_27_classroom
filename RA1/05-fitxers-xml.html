Lectura i escriptura de fitxers XML amb DOM

Com es representa un XML a memòria amb DOM, com s'escriu a partir d'un fitxer de text pla i com es llegeix, tant si en coneixes l'estructura com si no, gestionant les excepcions pròpies de DOM.

  • Explicar com DOM representa un XML a memòria.

  • Gestionar les excepcions pròpies de DOM.

1. Què és XML

XML (eXtensible Markup Language) és un format de text que guarda informació estructurada amb etiquetes. Com CSV i JSON, serveix per intercanviar dades entre aplicacions.

En aquestes notes treballarem amb aquest fitxer, alumnes.xml:

alumnes.xml XML 
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<alumnes>
  <alumne id="1">
    <nom>Anna</nom>
    <cognoms>Puig Serra</cognoms>
    <edat>19</edat>
    <nota_mitjana>8.5</nota_mitjana>
  </alumne>
  <alumne id="2">
    <nom>Marc</nom>
    <cognoms>Vidal Roca</cognoms>
    <edat>20</edat>
    <nota_mitjana>6.0</nota_mitjana>
  </alumne>
</alumnes>

La primera línia és la declaració: indica la versió d'XML i la codificació del fitxer.

2. Conceptes bàsics

2.1 Les peces d'un XML

  • Node: qualsevol peça de l'arbre. És el nom genèric: un element, un atribut o un text són tots nodes.
  • Element: una etiqueta amb el seu contingut, des de l'obertura fins al tancament. Exemple: <nom>Anna</nom>.
  • Element arrel: l'element que ho conté tot. Només n'hi pot haver un. Exemple: <alumnes>.
  • Atribut: una dada extra escrita dins de l'etiqueta d'obertura, en format nom="valor". Exemple: id="1".
  • Text: el contingut escrit entre l'obertura i el tancament d'un element. Exemple: Anna.

2.2 Element fulla i element no-fulla

Per recórrer un XML del qual no coneixem l'estructura (apartat 6), cal distingir dos tipus d'elements:

  • Element no-fulla: té almenys un fill que és un element. Exemple: <alumnes> i <alumne>. Són els contenidors, els "registres".
  • Element fulla: no té cap fill que sigui un element. Només conté text, o res. Exemple: <nom>, <cognoms>, <edat>, <nota_mitjana>. Són els "camps".

Per tant, <alumne> té alhora fills de text i fills element. Per això, quan recorrem l'arbre:

  • Cal comprovar el tipus de cada node amb getNodeType() i quedar-se només amb els Node.ELEMENT_NODE.
  • Per saber si un element és fulla, cal mirar si algun dels seus fills és un element. No n'hi ha prou de comptar quants fills té.

DOM (Document Object Model) treballa sempre amb un arbre de nodes a memòria:

  • Per escriure, construïm l'arbre a memòria i, quan és complet, el bolquem a un fitxer.
  • Per llegir, DOM carrega tot el fitxer de cop i construeix l'arbre a memòria. Després el programa el recorre.

Tot el necessari és al JDK: no cal cap llibreria externa.

4. Escriure XML amb DOM

Partim d'un fitxer de text pla, alumnes.txt, amb un alumne per línia i els camps separats per ;:

alumnes.txt Text 
1;Anna;Puig Serra;19;8.5
2;Marc;Vidal Roca;20;6.0

Volem obtenir l'alumnes.xml de l'apartat 1.

4.1 Els passos

  1. Llegir les línies del fitxer d'entrada: Files.readAllLines(...).
  2. Crear un document buit: DocumentBuilder.newDocument().
  3. Crear l'element arrel i penjar-lo del document: createElement(...) i appendChild(...).
  4. Per cada línia, crear un <alumne> amb l'atribut id i els seus fills, i penjar-lo de l'arrel.
  5. Bolcar l'arbre al fitxer de sortida amb un Transformer.

4.2 Codi complet

AlumnesToXML.java Java 
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

import javax.xml.parsers.DocumentBuilder;
import javax.xml.parsers.DocumentBuilderFactory;
import javax.xml.parsers.ParserConfigurationException;
import javax.xml.transform.OutputKeys;
import javax.xml.transform.Transformer;
import javax.xml.transform.TransformerException;
import javax.xml.transform.TransformerFactory;
import javax.xml.transform.TransformerFactoryConfigurationError;
import javax.xml.transform.dom.DOMSource;
import javax.xml.transform.stream.StreamResult;

import org.w3c.dom.Document;
import org.w3c.dom.Element;

public class AlumnesToXML {

    public static void main(String[] args) {
        Path entrada = Path.of ("alumnes.txt");
        Path sortidaXML = Path.of ("alumnes.xml");


        try {
            //Pas 1: Llegir el fitxer d'entrada i crear el document
            Document doc = crearDocument(entrada);
            //Pas 2: Amb el document creat, escriure'l al fitxer XML
            EscriureXML(doc,sortidaXML);
        } catch (ParserConfigurationException e) {
            System.out.println("Error a la configuració del parser " + e.getMessage());
        } catch (IOException e) {
            System.out.println("Error tractant fitxer d'entrada o sortida " + e.getMessage());
        } catch (Exception e) {
            System.out.println("Excepció general " + e.getMessage());
        }
        
    }

    public static Document crearDocument(Path entrada) throws ParserConfigurationException, IOException, Exception {
        List<String> linies = Files.readAllLines(entrada,StandardCharsets.UTF_8);

// La instància del DocumentBuilder es pot obtenir d'aquesta forma més compacta
        DocumentBuilder builder = DocumentBuilderFactory.newInstance().newDocumentBuilder();

// Es pot fer d'aquesta forma menys compacta
        //DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
        //DocumentBuilder builder = dbf.newDocumentBuilder();

        Document doc = builder.newDocument();

        Element arrel = doc.createElement("alumnes");
        doc.appendChild(arrel);

        for (String linia: linies) {
            if (linia.isBlank()) continue;

            String[] camps = linia.split(";",-1);

            Element alumne = doc.createElement("alumne");
            alumne.setAttribute("id", camps[0].trim());

            AfegirFill(doc,alumne,"nom",camps[1]);
            AfegirFill(doc,alumne,"cognoms",camps[2]);
            AfegirFill(doc,alumne,"edat",camps[3]);
            AfegirFill(doc,alumne,"nota_mitjana",camps[4]);

            arrel.appendChild(alumne);
        }
        return doc;
    }

    public static void AfegirFill (Document doc,Element pare,String etiqueta, String text) {
        Element fill = doc.createElement(etiqueta);
        fill.setTextContent(text.trim());
        pare.appendChild(fill);
    }

    public static void EscriureXML(Document doc, Path sortidaXML) throws TransformerFactoryConfigurationError, 
                                                                         TransformerException, 
                                                                         IOException, Exception {
        
        Transformer t = TransformerFactory.newInstance().newTransformer();

        t.setOutputProperty(OutputKeys.ENCODING, "UTF-8");
        t.setOutputProperty(OutputKeys.INDENT, "yes");
        t.setOutputProperty("{http://xml.apache.org/xslt}indent-amount", "2");

        try (BufferedWriter bw = Files.newBufferedWriter(sortidaXML, StandardCharsets.UTF_8)) {
            t.transform(new DOMSource(doc), new StreamResult(bw));
        }
        

    }
}

4.3 Mètodes que cal recordar

MètodeQuè fa
Files.readAllLines(ruta, UTF_8)Llegeix totes les línies del fitxer en una List<String>
builder.newDocument()Crea un document buit a memòria
doc.createElement("x")Crea un element <x>, encara sense penjar de l'arbre
pare.appendChild(fill)Penja un node com a darrer fill d'un altre
element.setAttribute("x", valor)Afegeix o modifica l'atribut x
element.setTextContent(text)Posa el text d'un element
TransformerFactory.newInstance().newTransformer()Crea l'objecte que converteix l'arbre en text
t.setOutputProperty(...)Configura la sortida: codificació, indentació...
t.transform(new DOMSource(doc), new StreamResult(...))Bolca l'arbre a la sortida
Files.newBufferedWriter(ruta, UTF_8)Obre el fitxer de sortida per escriure-hi

Compte

createElement() només crea l'element, no el posa a l'arbre. Si oblides l'appendChild(), l'element no apareixerà al fitxer, i no hi haurà cap error que t'avisi.

Compte

StreamResult no té cap constructor que accepti un Path. Per això li passem un BufferedWriter obtingut amb Files.newBufferedWriter(...). La codificació del Writer i la de OutputKeys.ENCODING han de coincidir. Si no, la capçalera de l'XML diria UTF-8 però el fitxer estaria escrit en una altra codificació.

Recorda

El Transformer escapa automàticament els caràcters especials en escriure el fitxer. Si un cognom conté &, al fitxer apareixerà &amp; i l'XML continuarà sent vàlid.

5. Llegir XML amb DOM coneixent l'estructura

Si sabem com és l'XML per dins (l'arrel es diu alumnes, cada registre és un alumne, els camps es diuen nom, cognoms...), podem anar directament a buscar cada element pel seu nom.

5.1 Els quatre passos

  1. Crear una fàbrica: DocumentBuilderFactory.
  2. Obtenir-ne un constructor: DocumentBuilder.
  3. Llegir el fitxer i obtenir l'arbre: Document.
  4. Recórrer l'arbre: buscar elements i llegir-ne el text o els atributs.

5.2 Codi complet

LlegirAlumnesDOM.java Java 
import javax.xml.parsers.DocumentBuilder;
import javax.xml.parsers.DocumentBuilderFactory;
import javax.xml.parsers.ParserConfigurationException;
import org.w3c.dom.Document;
import org.w3c.dom.Element;
import org.w3c.dom.NodeList;
import org.xml.sax.SAXException;

import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;

public class LlegirAlumnesDOM {

    public static void main(String[] args) {
        Path ruta = Path.of("alumnes.xml");

        // Comprovem que el fitxer existeix abans de llegir-lo
        if (!Files.exists(ruta)) {
            System.out.println("No existeix el fitxer: " + ruta.toAbsolutePath());
            return;
        }

        // try-with-resources: el flux es tanca sol en acabar
        try (InputStream entrada = Files.newInputStream(ruta)) {

            // 1. Fàbrica de constructors de documents
            DocumentBuilderFactory factory = DocumentBuilderFactory.newInstance();

            // 2. Constructor que farà la lectura
            DocumentBuilder builder = factory.newDocumentBuilder();

            // 3. Llegim el fitxer: tot l'XML queda a memòria com un arbre
            Document doc = builder.parse(entrada);
            doc.getDocumentElement().normalize(); // fusiona nodes de text adjacents

            // Element arrel
            System.out.println("Arrel: " + doc.getDocumentElement().getNodeName());

            // 4. Busquem tots els elements <alumne>
            NodeList llista = doc.getElementsByTagName("alumne");

            for (int i = 0; i < llista.getLength(); i++) {
                Element alumne = (Element) llista.item(i);

                // Atribut de l'element
                String id = alumne.getAttribute("id");

                // Text dels elements fills
                String nom     = alumne.getElementsByTagName("nom").item(0).getTextContent();
                String cognoms = alumne.getElementsByTagName("cognoms").item(0).getTextContent();
                String nota    = alumne.getElementsByTagName("nota_mitjana").item(0).getTextContent();

                System.out.println(id + " - " + nom + " " + cognoms + " - " + nota);
            }

        } catch (SAXException e) {
            System.err.println("L'XML no és vàlid: " + e.getMessage());
        } catch (ParserConfigurationException e) {
            System.err.println("Error a la configuració del parser: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("Error en llegir el fitxer: " + e.getMessage());
        }
    }
}

6. Llegir XML amb DOM sense conèixer l'estructura

I si no sabem com es diu l'arrel, quines etiquetes hi ha ni quins atributs tenen? Llavors no podem fer getElementsByTagName("alumne"), perquè no sabem que existeix alumne.

La solució és recórrer l'arbre de manera recursiva, començant per l'arrel (que sempre obtenim amb getDocumentElement()) i baixant fill a fill. Per a cada node que visitem:

  • Si no és un element (per exemple, un node de text de la indentació, apartat 2.3), no fem res.
  • Si és un element fulla (apartat 2.2), en mostrem el nom i el text i ja no baixem més.
  • Si és un element no-fulla, en mostrem el nom i tornem a cridar el mateix mètode per a cadascun dels seus fills.

Els dos primers casos són els casos base de la recursió: aturen la crida. El tercer és el cas recursiu. 

flowchart TD

    Q1{"És un<br/>ELEMENT_NODE?"}
    B1["return<br/>(cas base 1)"]
    AT["Afegir nom<br/>i atributs a la línia"]
    Q2{"esFulla(node)?"}
    B2["Mostrar nom: text<br/>return (cas base 2)"]
    R["Mostrar nom<br/>recorrer(fill, nivell + 1)<br/>per a cada fill"]

6.1 Codi complet

XMLToAlumnes.java Java 
import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;

import javax.xml.parsers.DocumentBuilder;
import javax.xml.parsers.DocumentBuilderFactory;
import javax.xml.parsers.ParserConfigurationException;

import org.w3c.dom.Document;
import org.w3c.dom.Element;
import org.w3c.dom.NamedNodeMap;
import org.w3c.dom.Node;
import org.w3c.dom.NodeList;
import org.xml.sax.SAXException;
import org.xml.sax.SAXParseException;

/**
 * Llegeix un XML amb DOM i en mostra el contingut sense conèixer-ne l'estructura.
 *
 * Important: amb DOM, builder.parse() llegeix TOT el fitxer i construeix l'arbre
 * sencer en memòria. Només després el recorrem i el mostrem.
 */
public class XMLToAlumnes {

    public static void main(String[] args) {
        Path entradaXML = Path.of("alumnes.xml");

        try {
            Document doc = obtenirDocument(entradaXML);
            Element arrel = doc.getDocumentElement();

            // Comencem el recorregut recursiu per l'arrel, al nivell 0
            recorrer(arrel, 0);

        } catch (SAXParseException e) {
            // Subclasse de SAXException: XML mal format, ens diu on és l'error
            System.err.printf("XML mal format (línia %d, columna %d): %s%n",
                    e.getLineNumber(), e.getColumnNumber(), e.getMessage());
        } catch (SAXException e) {
            System.err.println("Error en parsejar l'XML: " + e.getMessage());
        } catch (ParserConfigurationException e) {
            System.err.println("Error a la configuració del parser: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("Error en llegir el fitxer d'entrada: " + e.getMessage());
        }
    }

    /**
     * Carrega el fitxer XML (Path de NIO) i retorna l'arbre DOM.
     * parse() no accepta un Path, per això li passem un InputStream de NIO.
     */
    public static Document obtenirDocument(Path entradaXML)
            throws IOException, ParserConfigurationException, SAXException {

        DocumentBuilder builder = DocumentBuilderFactory.newInstance().newDocumentBuilder();

        try (InputStream is = Files.newInputStream(entradaXML)) {
            Document doc = builder.parse(is);
            doc.getDocumentElement().normalize();   // fusiona nodes de text adjacents
            return doc;
        }
    }

    /**
     * Recorre recursivament l'arbre a partir d'un node.
     *  - Cas base 1: el node no és un element (text de la indentació) -> no fem res.
     *  - Cas base 2: element fulla (només conté text) -> el mostrem i tornem.
     *  - Cas recursiu: element pare -> el mostrem i explorem els seus fills.
     *
     * node:   node que estem visitant
     * nivell: profunditat dins l'arbre (0 = arrel, 1 = registres com <alumne>..., 
     *                                   2 = camps com <nom>)
     */
    public static void recorrer(Node node, int nivell) {
        // Cas base 1: només tractem elements; els nodes de text de la indentació s'ignoren
        if (node.getNodeType() != Node.ELEMENT_NODE) return;

        StringBuilder linia = new StringBuilder("  ".repeat(nivell) + node.getNodeName());

        // Afegim els atributs de l'element (p. ex. id), sigui quin sigui el seu nom
        NamedNodeMap atributs = node.getAttributes();
        for (int i = 0; i < atributs.getLength(); i++) {
            Node at = atributs.item(i);
            linia.append(" ").append(at.getNodeName())
                 .append(" = ").append(at.getNodeValue());
        }

        // Cas base 2: element fulla (nom, cognoms...) -> mostrem nom i text a la mateixa línia
        if (esFulla(node)) {
            linia.append(": ").append(node.getTextContent().trim());
            System.out.println(linia);
            return;
        }

        // Element pare: separador només per als registres (fills directes de l'arrel)
        if (nivell == 1) {
            System.out.println("-".repeat(40));
        } 

        System.out.println(linia);

        // Cas recursiu: explorem els fills un nivell més avall
        NodeList fills = node.getChildNodes();
        for (int i = 0; i < fills.getLength(); i++) {
            recorrer(fills.item(i), nivell + 1);
        }
    }

    /**
     * Un element és fulla si no té cap fill de tipus element (només text, o res).
     * Atenció: un element buit també es considera fulla.
     */
    static boolean esFulla(Node node) {
        NodeList fills = node.getChildNodes();
        for (int i = 0; i < fills.getLength(); i++) {
            if (fills.item(i).getNodeType() == Node.ELEMENT_NODE) return false;
        }
        return true;
    }
}

7. Excepcions: per què apareix SAX si fem servir DOM

builder.parse() declara SAXException, i el compilador ens obliga a gestionar-la, tot i que estem fent servir DOM. El motiu és que el parser DOM de Java es construeix sobre SAX:

  1. SAX llegeix el fitxer seqüencialment i genera esdeveniments: "comença un element", "hi ha text", "acaba un element"...
  2. DOM escolta aquests esdeveniments i, a partir d'ells, va muntant l'arbre a memòria.

Si l'XML està mal format, qui se n'adona és SAX, i per això l'error arriba com a SAXException. Normalment arriba la subclasse SAXParseException, que indica la línia i la columna de l'error.

Per exemple, si a alumnes.xml canviem </edat> per </edad>:

Sortida d'error Sortida 
XML mal format (línia 6, columna 15): The element type "edat" must be terminated by the matching end-tag "</edat>".
ExcepcióQuan es produeix
IOExceptionEl fitxer no existeix, no es pot llegir o no es pot escriure
ParserConfigurationExceptionNo es pot crear el DocumentBuilder amb la configuració demanada
SAXException / SAXParseExceptionL'XML està mal format (lectura)
TransformerExceptionError en bolcar l'arbre a la sortida (escriptura)

Compte

SAXParseException és subclasse de SAXException. Al catch, la més específica ha d'anar primer o el codi no compilarà.

Recorda

DOM carrega tot el document a memòria. Va bé per a fitxers petits o mitjans. Per a fitxers molt grans és més adequat SAX, que llegeix seqüencialment sense guardar-ho tot.

8.1 Part 1: la mateixa sortida, a fitxer

Requisits:
