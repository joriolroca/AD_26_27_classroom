Gestió de fitxers i directoris

Com Java representa les rutes amb Path i actua sobre el disc amb Files: consultar, crear, copiar, moure i esborrar fitxers i directoris, recórrer-ne el contingut i tractar les excepcions que llança NIO.2.

Què aprendràs

En acabar aquesta unitat has de ser capaç de:

  • Distingir les dues APIs de Java per treballar amb fitxers i justificar per què es fa servir NIO.2.
  • Representar i manipular rutes amb la interfície Path.

  • Identificar les excepcions que llança NIO.2 i tractar-les de manera específica.
  • Llistar i recórrer el contingut d'un directori.

1.1 L'API actual: NIO.2

Un dels canvis que introdueix aquesta API és l'ús de la interfície Path. Fixeu-vos que mitjançant Path declarem la ruta del fitxer amb el qual es voldran dur a terme determinades accions.

Per altra banda també disposem de la classe Files per tal de dur a terme les operacions (comprovar existència, crear fitxer, etc. ) un cop hem declarat el Path. És important remarcar que Path per si sol no representa l'existència d'un fitxer o un directori, sols indica la seva ruta.

ExempleNio.java Java 
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class ExempleNio {
    public static void main(String[] args) throws IOException {
        Path dir = Path.of("dades");               // representa la ruta "dades" (encara no crea res)
        Path f   = dir.resolve("notes.txt");       // representa la ruta "dades/notes.txt"

        Files.createDirectories(dir);              // crea el directori i els pares que faltin
        Files.createFile(f);                       // crea el fitxer buit; si ja existeix llança una excepció

        System.out.println(Files.exists(f));       // true: comprova si existeix al disc
        System.out.println(f.getFileName());       // notes.txt: el nom, sense la ruta
        System.out.println(Files.size(f));         // 0: la mida en bytes

        Files.delete(f);                           // esborra el fitxer; si falla llança una excepció que diu per què
    }
}

El codi nou s'escriu amb NIO.2 perquè

  • Els errors es notifiquen amb excepcions que indiquen la causa (apartat 4).
  • Té operacions que java.io.File no té: copiar, moure amb garanties, recórrer arbres, llegir atributs.
  • Separa la ruta (Path) de les operacions (Files), i això fa el codi més clar.

2. NIO2-PATH

Un **Path és una ruta: una seqüència de noms de directoris acabada en un fitxer o directori. No accedeix al disc ni modifica res: aquestes operacions les fa la classe Files.**

ExemplePath.java Java 
import java.nio.file.Path;

public class ExemplePath {
    public static void main(String[] args) {
        // Path.of() uneix els fragments amb el separador del sistema: / a Linux, \ a Windows
        Path p = Path.of("dades", "2026", "vendes.csv");

        System.out.println(p.getFileName());      // vendes.csv      -> l'últim element de la ruta
        System.out.println(p.getParent());        // dades/2026      -> la ruta sense l'últim element
        System.out.println(p.isAbsolute());       // false           -> és relativa
        System.out.println(p.toAbsolutePath());   // /home/alumne/projecte/dades/2026/vendes.csv
                                                  //                 -> la converteix en absoluta

        Path base = Path.of("dades");
        System.out.println(base.resolve("clients.csv"));
        // dades/clients.csv -> afegeix una ruta al final d'una altra

        System.out.println(p.resolveSibling("compres.csv"));
        // dades/2026/compres.csv -> substitueix l'últim element (útil per reanomenar)

        System.out.println(base.relativize(p));
        // 2026/vendes.csv -> el camí per anar de "dades" a "dades/2026/vendes.csv"

        System.out.println(Path.of("dades/./2026/../clients.csv").normalize());
        // dades/clients.csv -> elimina els "." i resol els ".."
    }
}
MètodeRetornaQuè fa
Path.of(...)PathCrea una ruta a partir d'un o més fragments
getFileName()PathL'últim element de la ruta
getParent()PathLa ruta sense l'últim element, o null si no en té
isAbsolute()booleanIndica si la ruta és absoluta
toAbsolutePath()PathConverteix la ruta en absoluta
resolve(altra)PathAfegeix altra al final de la ruta
resolveSibling(nom)PathCanvia l'últim element per nom
relativize(altra)PathCalcula el camí relatiu per anar fins a altra
normalize()PathElimina els . i resol els ..

normalize() neteja una ruta d'elements redundants:

  • . vol dir "el directori actual", així que s'elimina: dades/./2026 → dades/2026.
  • .. vol dir "el directori pare", així que anul·la l'element anterior: 2026/.. desapareix.
Text 
dades/./2026/../clients.csv
dades/2026/../clients.csv       <- s'elimina el "."
dades/clients.csv               <- "2026" i ".." s'anul·len

Nota

si escrius les rutes amb Path.of("dades", "2026") en lloc de "dades\\2026", el codi funciona igual a qualsevol sistema operatiu.

3. NIO2-FILES

Files és el que actua sobre el disc. Fa les operacions de crear, copiar, moure, esborrar, llegir, escriure, comprovar si existeix...

3.1 Crear i consultar

CrearIConsultar.java Java 
import java.io.IOException;
import java.nio.file.*;

public class CrearIConsultar {
    public static void main(String[] args) throws IOException {   // les excepcions es tracten a l'apartat 4
        Path dir    = Path.of("dades", "informes");
        Path fitxer = dir.resolve("resum.txt");                    // dades/informes/resum.txt

        Files.createDirectories(dir);        // crea "dades" i "informes" si no existeixen
        if (Files.notExists(fitxer)) {       // true si el fitxer NO existeix
            Files.createFile(fitxer);        // crea un fitxer buit
        }

        System.out.println("Existeix?        " + Files.exists(fitxer));               // existeix al disc?
        System.out.println("És fitxer?       " + Files.isRegularFile(fitxer));        // és un fitxer (no un directori)?
        System.out.println("És directori?    " + Files.isDirectory(dir));             // és un directori?
        System.out.println("Mida:            " + Files.size(fitxer) + " bytes");      // mida en bytes
        System.out.println("Modificat:       " + Files.getLastModifiedTime(fitxer));  // data de l'última modificació
        System.out.println("Es pot escriure? " + Files.isWritable(fitxer));           // tenim permís d'escriptura?
    }
}

Fixeu-vos que per l'arxiu "resum.txt" hem fet directament un resolve i no un Path.of("resum.txt"). Per què?

MètodeQuè fa
createDirectory(p)Crea un sol directori. Falla si el pare no existeix o si ja existeix
createDirectories(p)Crea el directori i tots els pares que faltin. No falla si ja existeix
createFile(p)Crea un fitxer buit. Falla si ja existeix
exists(p) / notExists(p)Comprova si la ruta existeix / no existeix
isRegularFile(p) / isDirectory(p)Distingeix fitxer de directori
size(p)Mida en bytes
getLastModifiedTime(p)Data i hora de l'última modificació
isReadable(p) / isWritable(p)Permisos de lectura / escriptura

Compte

createFile() no crea els directoris pares. Si dades/informes no existeix, llança NoSuchFileException. Crida abans createDirectories().

3.2 Copiar, moure i esborrar

CopiarMoureEsborrar.java Java 
import java.io.IOException;
import java.nio.file.*;

public class CopiarMoureEsborrar {
    public static void main(String[] args) throws IOException {
        Path original = Path.of("dades", "informes", "resum.txt");
        Path copia    = Path.of("backup", "resum.txt");

        Files.createDirectories(copia.getParent());   // crea "backup" si no existeix

        // COPIAR: REPLACE_EXISTING sobreescriu el destí si ja existeix.
        // Sense aquesta opció, si el destí existeix es llança una excepció.
        Files.copy(original, copia, StandardCopyOption.REPLACE_EXISTING);

        // MOURE o CANVIAR EL NOM: és la mateixa operació.
        // resolveSibling() canvia el nom: backup/resum.txt -> backup/resum-2026.txt
        Path reanomenat = copia.resolveSibling("resum-2026.txt");
        Files.move(copia, reanomenat, StandardCopyOption.REPLACE_EXISTING);

        // ESBORRAR
        Files.delete(reanomenat);                             // esborra; llança una excepció si no existeix
        boolean esborrat = Files.deleteIfExists(reanomenat);  // esborra si existeix; si no, retorna false
        System.out.println("S'ha esborrat alguna cosa? " + esborrat);   // false: ja no hi era
    }
}

Nota

StandardCopyOption.ATOMIC_MOVE garanteix que el moviment es fa sencer o no es fa. És útil quan un altre programa vigila la carpeta de destí i no ha de veure mai un fitxer a mitges.

Compte

Files.delete() només esborra directoris buits. Per esborrar un directori amb contingut, cal esborrar primer tot el que conté.

4. Les excepcions de NIO.2

A diferència de java.io.File, els mètodes de Files no retornen false quan fallen: llancen una excepció que diu exactament què ha passat. Totes són checked i hereten d'IOException.

ExcepcióQuan salta
NoSuchFileExceptionLa ruta (o el seu directori pare) no existeix
FileAlreadyExistsExceptioncreateFile(), copy() o move() sense REPLACE_EXISTING i el destí ja existeix
DirectoryNotEmptyExceptionIntentes esborrar un directori que no és buit
NotDirectoryExceptionEsperaves un directori i és un fitxer
AccessDeniedExceptionNo tens permisos sobre la ruta
IOExceptionQualsevol altre error d'entrada/sortida

4.1 Tractar cada error per separat

Aprofitem els catch múltiples: primer les excepcions específiques i, al final, IOException.

EsborrarSegur.java Java 
import java.io.IOException;
import java.nio.file.*;

public class EsborrarSegur {

    public static void esborrar(Path p) {
        try {
            Files.delete(p);                                    // pot fallar per diversos motius
            System.out.println("Esborrat: " + p);

        } catch (NoSuchFileException e) {
            System.out.println("No existeix: " + e.getFile());  // getFile(): la ruta que ha fallat
        } catch (DirectoryNotEmptyException e) {
            System.out.println("El directori no és buit: " + e.getFile());
        } catch (AccessDeniedException e) {
            System.out.println("Sense permisos: " + e.getFile());
        } catch (IOException e) {                               // sempre l'última: és la més general
            System.out.println("Error inesperat: " + e.getMessage());
        }
    }

    public static void main(String[] args) throws IOException {
        Path dir = Path.of("proves");
        Files.createDirectories(dir);                       // crea el directori "proves"
        Files.writeString(dir.resolve("a.txt"), "hola");    // crea proves/a.txt amb el text "hola"

        esborrar(Path.of("no-hi-es.txt"));   // No existeix: no-hi-es.txt
        esborrar(dir);                       // El directori no és buit: proves
        esborrar(dir.resolve("a.txt"));      // Esborrat: proves/a.txt
        esborrar(dir);                       // Esborrat: proves (ara ja és buit)
    }
}

Recorda

si poses catch (IOException e) abans que els altres, el compilador dona error, perquè els catch específics no s'executarien mai.

4.2 Llançar i declarar: throw i throws

També podem llançar aquestes excepcions nosaltres mateixos per validar una ruta abans de treballar-hi. El mètode les declara amb throws i qui el crida decideix com tractar-les.

Validacions.java Java 
import java.io.IOException;
import java.nio.file.*;

public class Validacions {

    /** Comprova que la ruta existeix i és un directori. */
    public static void comprovarDirectori(Path dir) throws IOException {
        if (Files.notExists(dir)) {
            throw new NoSuchFileException(dir.toString());     // llancem l'excepció amb la ruta
        }
        if (!Files.isDirectory(dir)) {
            throw new NotDirectoryException(dir.toString());
        }
    }

    public static void main(String[] args) {
        Path dir = Path.of("descarregues");
        try {
            comprovarDirectori(dir);
            System.out.println("Directori correcte: " + dir.toAbsolutePath());
        } catch (NoSuchFileException e) {
            System.out.println("No existeix: " + e.getFile());
        } catch (NotDirectoryException e) {
            System.out.println("No és un directori: " + e.getFile());
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}

Compte

aquests Stream mantenen oberts recursos del sistema operatiu. Obre'ls sempre dins d'un try-with-resources.

Els fragments d'aquest apartat van dins d'un mètode que declara throws IOException i necessiten els imports java.nio.file.*, java.util.* i java.util.stream.Stream.

5.1 Llistar un directori

És l'operació amb la qual recorrem els elements que hi ha en un directori. És una operació de lectura.

Tot seguit veureu dues versions del mateix codi.

Versió 1: Aquí contingut es pot recórrer amb un for-each perquè és un Iterable: DirectoryStream és una interfície que estén les interfícies Iterable i Closeable.

Java Java 
try (DirectoryStream<Path> contingut = Files.newDirectoryStream(Path.of("dades"))) {
    for (Path p : contingut) {
        if (Files.isDirectory(p)) {
            System.out.println("[DIR] " + p.getFileName());
        } else {
            System.out.println("[FIT] " + p.getFileName());
        }
    }
}

Versió 2: contingut és un Stream i es recorre amb forEach() i una expressió lambda (p -> { ... }). La condició es resol amb l'operador ternari (condició ? valor1 : valor2).

Java Java 
// Files.list(): un Stream amb el contingut del primer nivell de "dades"
try (Stream<Path> contingut = Files.list(Path.of("dades"))) {
    contingut.forEach(p -> {                                   // per a cada element...
        String tipus = Files.isDirectory(p) ? "[DIR] " : "[FIT] ";
        System.out.println(tipus + p.getFileName());           // ...mostra el tipus i el nom
    });
}   // aquí es tanca l'Stream

5.2 Cercar fitxers amb un filtre

Java Java 
// Mostra els fitxers .csv de 'dir' i baixa als subdirectoris fins on indiquem a 'nivellsRestants'. Si volem arribar fins a 5 subdirectoris (per exemple C:\user\acces\dades\curs\2026), nivellsRestants = 5. 

//Fixeu-vos la crida recursiva que fa a la mateixa funció

static void cercarCsv(Path dir, int nivellsRestants) throws IOException {
    try (DirectoryStream<Path> contingut = Files.newDirectoryStream(dir)) {
        for (Path p : contingut) {
            String nom = p.getFileName().toString();

            if (Files.isRegularFile(p) && nom.endsWith(".csv")) {
                System.out.println(p);                     // és un .csv: el mostrem
            } else if (Files.isDirectory(p) && nivellsRestants > 1) {
                cercarCsv(p, nivellsRestants - 1);         // és una carpeta: hi entrem
            }
        }
    }
}
